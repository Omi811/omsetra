# Security and privacy

This repository is public. Do not attach real bank statements, invoices, customer information, credentials, private keys or payment tokens to issues or discussions.

For a product bug, provide a minimal reproduction using fictional data. A dedicated private security-reporting address is not configured yet. Do not disclose exploitable details publicly; check the repository's Security tab for private reporting availability before reporting a vulnerability.

The public demo uses fictional records. Business workspaces require authentication and ownership checks. Live payments remain disabled while provider approval and launch configuration are pending.
